نبذة تعريفية عن التطبيق
نكت 1400 — ألف وأربعمئة نكتة تُضحّك من القلب 😂

تطبيق ترفيهي عربي وفرنسي يجمع 1400 نكتة مختارة، مصنّفة بعناية لتلائم كل مزاج وكل مناسبة. يعمل بدون إنترنت (PWA) ويمكن تثبيته على هاتفك مباشرة من المتصفح.

أبرز المزايا:

🗂️ تصنيفات غنية: نكت عربية حسب البلد (مصر، السعودية، الجزائر، المغرب…)، ونكت أجنبية حسب القارة والبلد، ونكت حسب العمر (للصغار، للمتزوجين، +18)، ونكت مشهورة ونكت المسابقات العالمية.
🎯 أقسام متنوّعة: نكت المدرسة، العمل، الأطباء، الحمّاوة، التكنولوجيا، الحيوانات، وجوحة…
⭐ تقييم ومفضّلة: قيّم كل نكتة واحفظ المفضّلة لديك.
🔍 بحث فوري ونكتة عشوائية و«نكتة اليوم».
🎵 موسيقى هادئة مدمجة مع زر تشغيل/إيقاف.
🌍 لغتان: العربية والفرنسية.
📴 يعمل أوفلاين وسريع وخفيف.
